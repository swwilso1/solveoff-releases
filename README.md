# SolveOff releases

Installers and automatic-update files for **SolveOff**, the head-to-head problem race app
for classroom touch boards.

Download the latest version from the [Releases](../../releases/latest) page:

| Computer | File |
| --- | --- |
| Mac (Apple Silicon or Intel) | `SolveOff_<version>_universal.dmg` |
| Windows PC (most PCs) | `SolveOff_<version>_x64-setup.exe` |
| Windows on ARM | `SolveOff_<version>_arm64-setup.exe` |

The Windows `-setup.exe` installs for the current user and doesn't need administrator rights.
School IT can use the `.msi` files instead for managed, all-users installs.

Once installed, SolveOff checks here for new versions and offers to update itself.
